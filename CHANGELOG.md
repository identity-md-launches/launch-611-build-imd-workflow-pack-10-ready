## 2026-10-02

Replaced the Access Pass body, re-checked the pack against the live API, and corrected the duplicate-check section of the README.

- **`workflows/06-subscription-pass.json` — removed.** Access Pass (PASS) sold a renewable, token-paid 30-day pass whose validity was read as an active status. That is the product the live Cadence (CDNC) launch already is: workflow `b41fdc9b-e5bf-4bae-b3a9-070eb80327ef`, launch 87, `SubscriptionRegistry` at `0x7bf4926e59d2fc450dc48e2ba88d8f3df361d64e` on Sepolia, which takes a fixed CDNC amount per thirty-day period and exposes `isActive(address)`. `GET https://api.imd.fun/publications?q=subscription` returns it, so the body was a duplicate the pack's own acceptance criteria forbid.
- **`workflows/06-custody-handoff.json` — added.** Custody Chain (CSTD) logs a consignment's chain of custody: a shipper opens a consignment for a `bytes32` manifest hash, the current holder offers the next leg by naming the next holder and paying a fixed CSTD carriage fee, the named holder collects that fee by accepting custody, and an offer the named holder has not accepted within exactly 7 days can be withdrawn. Same constraints as the other nine bodies, so the pack still ships ten.
- **`results.json` — regenerated.** A full `node check-workflows.mjs` run: all ten bodies returned HTTP 200 from `POST https://api.imd.fun/requests/check`, judged, with no blockers and no suggestions. The report now also carries `publicationSearches`: fifteen dated `GET https://api.imd.fun/publications?q=` searches with every publication each returned and why none is the same product. `custody chain`, `chain of custody`, `consignment`, `shipment`, `freight`, `cargo`, `courier`, `logistics`, `bill of lading` and `proof of delivery` return nothing at all; `custody` and `handover` return only publications that use the word in passing.
- **`check-workflows.mjs` — one addition.** The `PUBLICATION_SEARCHES` record above, copied into every report so a re-run cannot drop it, plus the `--help` line that says so. Validation, request and retry behaviour are unchanged.
- **`README.md` — two sections corrected.** The sixth product entry now describes Custody Chain. The duplicate-check section states exactly what the ten shipped bodies avoid; its old list claimed subscription-adjacent access products and credentials/badges were both excluded while the pack shipped one of each. Skill Credential stays, with how it differs from the live Badges (BDGE) launch, workflow `760a7259`: BDGE mints permissionless ERC-721 badge types for an anti-spam burn, with no expiry and holder-side burning, while SKIL mints nothing and keeps issuer-scoped records bound to an evidence hash and a `uint256` expiry. Publication and repository counts are from re-paging both catalogues on the same day.
